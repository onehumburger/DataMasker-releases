# 法律科技兵脱敏工具 · 发布通道

本仓库仅用于**试用版下载**与**版本清单**分发，不含源代码。

## 下载

前往 [Releases](../../releases/latest) 获取最新试用版：

| 平台 | 文件 |
|---|---|
| macOS (Apple Silicon) | `DataMasker-Trial-macOS-AppleSilicon-*.dmg` |
| macOS (Intel) | `DataMasker-Trial-macOS-Intel-*.dmg` |
| Windows | `DataMasker-Trial-Windows-Setup-*.exe` |

首次打开 macOS 版需在「系统设置 → 隐私与安全性」中允许运行。

## latest.json

`latest.json` 是应用内更新检查读取的版本清单，经 ed25519 签名。
应用只读取版本号，**不上传任何数据**；签名校验失败一律视为没有更新。

## 正式版

正式版不在本公开通道分发，请联系获取。
